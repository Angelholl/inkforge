**makensis 直编译参数链（踩坑实录）：**
- `MSYS_NO_PATHCONV=1 makensis /INPUTCHARSET UTF8 <模板>`——无 INPUTCHARSET 时按 ACP 解码，UTF-8 中文 MessageBox 行直接 Bad text encoding；MSYS 会把 `/INPUTCHARSET` 转成盘路径（`D:/Git/INPUTCHARSET=UTF8`）；
- 模板文件保持 UTF-8（git HEAD 即 UTF-8），**任何读写必须 latin1/字节保真**（utf8 读写会把 GBK/ACP 解码面打碎）；**模板内新增注释禁中文**（ACP 兜底路径会炸）；
- bash 双引号 `node -e` 内 `$INSTDIR` 会被 bash 变量展开吞掉——模板字符串拼接一律走脚本文件（Write 工具）不经 bash；
- 产物 OutFile 相对**模板所在目录**落 `nsis/nsis-output.exe`（非 cwd），编译后 cp 双落位（bundle/nsis + data/artifacts）。

**装机四点（全 PASS）：** ARP `HKCU\...\Uninstall\inkforge` DisplayVersion=0.2.0；装机位 migrations **12 个**；桌面壳起 sidecar 8787 health `{"ok":true,"version":"0.2.0"}`（生产库 %APPDATA%\dev.inkforge.app 只读探活 1 书无损）；前端 `index-DczAUPDW.js` 新 hash（装机位 dist 396 文件=staging 一致，根 hash 残留已清）。冒烟后进程收割恢复原态。
