## 2. 泛型原则：重合判定「载体驱动」，不硬编码任何节表

调研报告钉死的解析器行为给出本案的泛型地基——**解析器只认结构骨架（标题/表格/编号），内容无关**（plan 全局约束），且精炼全文**保留标题行**（剥 `#` 留题面，`settings-import.ts:121`）。于是：

**A 类重合（MD 正文 ↔ 本次导入抽出的结构化记录）的判定准则 = 「被抽取消费过的节」**：
- 解析器消费哪节是解析过程自身的既成事实（`includes('人物'/'大纲'/'矩阵'/'文风')` 命中节 + 悬置 H3 块，`settings-import.ts:494-542,447`）——引擎据此声明候选，与具体是哪本书、什么题材、几节骨架**完全无关**。
- 实现：preview DTO 增 `consumedSections: string[]`（服务端廉价改动）；书设置入口对已入库书=对 imports 归档原文重跑纯解析器即得同一清单（引擎确定性，N3 钉）。
- 剥除=在精炼 description 文本里按题面定位该节区段删除；**只作用于 description，绝不回流解析输入**（N1：剥后卡数不变）。
- 未被抽取的节（只活在 description）=无承载 → 引擎自动标「不可剥」。§5 类「部分承载」内容（前 23 章有蓝图、弧表是后续规划原料）泛型预置=保持双注入。
- **承载判定精确到片段（interim 实践发现，11-24）**：节被消费 ≠ 节内每段都被承载——如「**关系网**：一句话」这类粗体紧跟冒号的**标签行**解析器有意跳过不成卡（`settings-import.ts:271` 附近 label-skip 规则），该段是残段。引擎剥除准则=「归一化后出现在卡 setting/outline 行/伏笔 description/档案 source 的片段才可剥，残段保留」；节级判定只作预置展示，落稿按片段过滤。今晚 interim 稿即按此执行（§4 剥 4.1–4.4 留 4.5）。

**B 类重合（MD 正文 ↔ 蒸馏档案）**（评议裁定：MVP 只做确定性警示）：
- 档案输入是 owner 粘贴的参考作正文，不是本书章节；plot/spectrum/imitation 仅进 planner 参考槽，与 MD **无同槽双注入**——「保留一方」对它们是假选项面（调研报告表二）。
- 唯一同槽面=style：参考作档案的规则/样本与 description 中文风/规则类内容并存于 styleRules/fewShot。MVP=确定性警示（列「本书主/辅档案 × 消费过文风/规则类节」并存清单，处置走既有主/辅/权重/七维控件）。
- 「旧宇宙 vs 新宇宙」语义冲突（参考作同名人物/行为 vs 本文档设定）：LLM 对照 pass 列 **P2**；owner 坚持进 MVP 须带真实例证（评议要求）。

## 3. 方案骨架

### 3.1 引擎（纯函数，零 LLM，格式无关）

输入：description（当前库内值或导入草稿）+ 消费节清单（来自解析器/归档重解析）+ 绑定档案现状（style 主/辅）。
- 输出：「剥除预览 diff + 警示清单」；不落库、无 LLM、无书特异性知识。
- 作用层=库内 description 文本：对来源是 MD 设定集、纯文本世界观稿还是手填简介**一视同仁**；非骨架 txt 的「文档导入」本身是另一个入口扩展（P2 候选，见 §3.4）。

### 3.2 裁决→机制映射

| 选项 | 动作 |
|---|---|
| 保留 MD 正文 | description 不动 |
| 保留结构化承载（剥正文） | 按题面从 description 剥该节文本，记录/绑定零触碰 |
| 保持双注入（现状，原「融合/并存」改名） | 两路各喂各槽；默认项+回归钉 |
| 手改合并 | 用户在世界观编辑框直接改文本（已有 UI）；LLM 改写正典不做 |

### 3.3 入口（两入口共享同一引擎，泛型 owner 指认后的定位）

1. **书籍设置「清洗」按钮（MVP）**：对任意已入库书跑引擎→预览 diff→确认 PUT meta。不依赖导入流程，今晚这本只是首个试例。
2. **导入向导内嵌（P1）**：preview 后 apply 前跑同一引擎，裁决并入草稿确认屏——面向「以后每次导入任意大纲文档」的主流程，功能长期正身在①。
3. B 类 LLM 对照 + 向导勾档案预选（现绑定语义在详情页 `routes.ts:1082-1160`，预选=新增步骤，膨胀点）→ P2。

### 3.5 生成前融合确认门（v3 核心，owner 痛点直答）

**今晚「融合不好」的库内根因（实测）**：新书绑定面板只有 1 行绑定=本书「文风规范」主档，`weights_json={}`、`dims_json={}`、无辅档；owner 当晚 22:52–22:57 刚重蒸的阿美/仙家 v2 是**全局库存档，从未绑进这本书**——ch1 生成时 drafter 只看得到你自己 §10 派出的那一份规则。融合机构（主/辅 ≤4、档权重、七维来源、fewshot 开关）全部已存在，**缺的只是一道「生成前没人逼你把融合意图过一遍」的门**。

门形态：run 启动入口（生成/续写按钮处）挂前置检查——
1. 引擎跑 A 类（剥节候选）+ 现状绑定快照（主/辅/权重/fewshot）。
2. **一次 LLM 张力对照**（v2 中被降 P2 的 pass，按 owner 痛点升回 MVP）：输入=description+大纲产物 × 已绑与候选档案的 rulesText/structure，输出=张力对清单 `{条目, MD 侧, 档案侧, 性质: 拉扯|冗余|缺口(档案有MD无|MD有档案未绑), 建议偏向}`；行协议+降级不阻断（超时/解析失败→门退化为「仅 A 类+绑定快照」仍可确认放行）。
3. 弹出确认分页：每行**按机制诚实给选项**——style 行：偏向=权重滑条/维归属/剥 MD 文本/保持；planner 参考类行（plot/spectrum/imitation）：偏向=绑/不绑（附注「大纲卡落地格恒优先，档案只作参考」——不给它们造「剥 MD 靠档案」假选项，化解评议 R3）；A 类剥节行：剥/留。
4. 「确认并开始生成」=批量调既有端点（binding PUT+weights、meta PUT 剥节、绑定端点）→ 入队 run。取消=不落任何写。
5. 门可跳过（「不再提示」书级开关存 app_meta 或 books 列——计划期定），保证熟手不增摩擦。

入口②（书设置清洗按钮）与入口①（导入向导内嵌）降为**同一门的两个前置变体**：门是长期正身，两入口是它的两个调用点。

**门四钉（复议 B/C/A/D 采纳，11-24）**：
- **触发指纹哈希「实际注入面」而非活档案**：`description + book_style_profiles 绑定行(含 weights_json/dims_json) + books.style_fewshot_on + style_snapshot_json`（planner 参考类另加三个 profile 绑定列）。理由：档案重蒸不自动刷新快照（DEC-2026-1117-04 语义），哈希活档案会在不影响注入的变更上误弹、或漏掉快照真实变化。mandate/词表**不入指纹**（门不管它们，R6 正交）。指纹未变=直通不弹；**取消=零写且指纹不更新，下次生成必重弹**（防「取消」被误记为「已确认」）。
- **降级必须可见**：LLM 张力 pass 超时/解析失败→门退化为「仅 A 类+绑定快照」照常可确认放行，但门顶明示「本次未做张力对照」——静默降级制造虚假安心，比不弹更糟。
- **批量 apply 竞态（N5）**：确认=多端点批量写后入队；包装为**失败即中止、不入队**，门内显示失败项与已生效项；验收加故障注入（mock 一端点 500→无 run 入队、无半写）。
- **写入口一致性**：门内权重/维归属控件与书设置绑定面板是同一状态的两个写入口，复用同一 binding 端点；门写后快照刷新语义与 DEC-2026-1117-04（重蒸不自动刷新、需手动重绑）一致，计划期写明。

### 3.4 边界与非目标

- 不动生成管线槽装配；不动蒸馏作业输入模型；不做「章节自动反哺档案」（continuity 除外，已自动）；不触碰 mandate/落地格/章骨架；不做 LLM 改写正典；8k 档截断行为不变。
- MVP 不新增文档格式解析（纯 txt 世界观稿/大纲稿的独立导入器另案）。

- R4 预算警示联动：被夸大——剥只降字数，预警单向消失。
- R5 未参与对照的档案：入口②按书内已绑定档案全量对照，规避。
- R6 与 mandate 体系相邻易误解：真——验收加「清洗后 mandate/mustHaveBeats/骨架不变」回归钉。
- R7 存量书分叉：真——②先行论据（泛型后仍成立：任意存量书可洗）。
- N1 剥节不得回流解析输入：真——验收钉「剥后卡数/树/伏笔/绑定不变」。
- N2 向导预选=膨胀点：采纳出 MVP。
- N3 引擎确定性（书设置入口靠归档重解析）：真——验收钉「同输入重跑逐字节一致」；灾备=imports 归档 re-refine。

## 6. 验收口径（v3.1 全面改写：以门为正身，消 MATERIAL_CONFLICT）

- **引擎纯函数单测**：中性仿形夹具（《示例之作》系，沿内容无关律）+ v6 归档副本双型；A 类片段级承载判定（全量承载→预置剥；部分/未承载→保持/不可剥；标签行残段保留）；触发指纹计算（注入面哈希；重蒸活档案但快照未变→指纹不变→直通；取消零写→下次必弹）。
- **LLM 张力 pass**：canned 行协议用例（拉扯/冗余/缺口三性质各 ≥1、选项映射正确）；超时/解析失败→降级用例，且降级标记透传到门响应（可见降级断言）。
- **HTTP 批量确认**：全确认→binding/weights/meta 各端点按裁决生效+run 入队；故障注入（mock 一端点 500）→**中止不入队、无半写**、失败项回显（N5）；全「保持」路径=逐字节现状（回归钉）；确认写后回读 description 剥节正确且 characters/outline/伏笔/骨架/mandate 不变（N1/R6）；引擎重跑一致（N3）。
- **注入重放**：剥节后 drafter worldview 变短、其余槽逐字节不变；planner task 头窗不变（N4）。
- **GUI 未验证（owner 真实测试）点位**：门分页（首次生成弹出/无变化直通/变化重弹三态）、张力行偏向操作、可见降级横幅、取消后再生成必重弹、失败中止回显、书级不再提示。
