# 墨炉（Inkforge）意向书（用户逐条确认，2026-11-11）

- **产物定位：** 个人使用的全自动长篇小说生成流水线（非写作编辑器），本地为主（可切云端模型），GUI 操作
- **入口 A 续写模式：** 喂入已有小说 → 原作剧情蓝图勾画 → 续写
- **入口 B 生成模式：** 预设世界观/角色卡/规则 → 蓝图勾画 → 全新生成
- **风格系统（两模式共用）：** 预设文风/写作手法 + 参考小说片段提取（few-shot）+ MirrorNovel 式风格蒸馏，可组合挂载，前置规避文风漂移；**续写模式（A）不注入风格档案**，改用 voice-match 质检维度（原作正文即最强风格锚）
- **核心管线：** 蓝图规划 → 章节队列 → 逐章自动生成 → 自动质检 → 自动二次审稿 → 自动重写 → 挂机连产 20+ 章
- **连续性保障：** 几十万字长篇，自动摘要/伏笔/角色状态追踪，批次间不断线
- **人工介入点：** 跑完后抽查，点章重写；其余无人值守
- **技术来源：** 借鉴 Pagekin（连续性追踪/多版本/防重演）与 MirrorNovel（风格蒸馏）思路，代码主体重写（clean-room），技术栈按需求定
- **明确不做：** 人工写作编辑器、审稿流转、多人协作
