# Inkforge NSIS template

Baseline copied from `target/release/nsis/x64/installer.nsi`, generated by `@tauri-apps/cli@2.12.4` (`tauri build`, Tauri NSIS bundler), then extended with the C: drive install guard.
Upgrades: bump the pinned CLI, rebuild once, re-copy the generated baseline, and replay the `Inkforge*` additions in `inkforge-installer.nsi` (never edit the upstream logic).
Constraint: the template must never gain a fallback that installs to the system drive.
