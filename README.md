# 墨炉（Inkforge）

个人使用的全自动长篇小说生成流水线：蓝图 → 章节队列 → 逐章生成 → 质检 → 定点重写 → 连产挂机。本地运行，数据不出机。

## 声明（使用前必读）

- **本项目仅支持个人使用，禁止用于商业用途。**
- 本项目的风格蒸馏功能会从参考文本中提取并复现作品风格，**AI 生成作品可能与原作者风格雷同**，由此产生的著作权与相关责任由使用者自行承担。
- 生成内容全部由本地模型产生，本项目不设题材审查，使用者对产出内容负责。

## 功能

- **全自动单章管线**：草稿 → L0 确定性质检（长度/套话/重演/抄用/节拍/连续性）→ L1 引用证据质检 → 门控 → 最多 2 轮定点/整章重写 → 定稿
- **批量挂机**：整书 20+ 章连产，队列并发 1，失败章自动跳过，晨检报表
- **崩溃安全**：DB 持久化运行状态 + 租约心跳，进程被杀后断点续跑；残稿抢救；run 前 SQLite 快照；正文 append-only 永不就地覆盖
- **连续性管理**：自动章节摘要、角色状态、伏笔登记，供后续章节上下文引用
- **风格系统**：从样例文本离线蒸馏风格档案（量化规则 + few-shot 选段），逐章轮换注入；同源重复蒸馏自动升版本，旧档案不变
- **GUI**（Tauri 桌面壳 / 浏览器）：书架、章节详情与蓝图编辑、运行面板、阅读器、版本链与 word-diff 对比、仪表盘、选段重写、回滚、markdown 导出
- **角色路由**：草稿/质检/重写/摘要各角色可独立指定本地或云端模型（配置驱动）

## 环境要求

- Node.js ≥ 22.11，pnpm ≥ 9
- 桌面模式（可选）：Rust ≥ 1.77.2 + WebView2；不用桌面壳可直接浏览器访问
- 本地 LLM 端点：Anthropic Messages 协议（`/v1/messages`），默认指向 Strata 本地端点

## 安装与启动

```bash
pnpm install
cp .env.example .env   # 按注释填写：STRATA_BASE_URL / STRATA_API_KEY / STRATA_MODEL 三项必填
```

启动（二选一）：

```bash
# 方式一：启动器（起服务 + Edge app 模式开界面）
apps/server/scripts/start-inkforge.cmd

# 方式二：手动
pnpm dev:server    # 服务 http://localhost:8787
pnpm dev:web       # 浏览器 GUI（开发模式，可选；生产由服务托管静态页）
```

演示/无模型环境：`.env` 里设 `INKFORGE_MOCK=1`，全流程走确定性 mock，不调真模型。

## 使用流程

1. **建书**：书架页输入书名 → 建书
2. **蓝图**：详情页"蓝图编辑"填章号与 JSON 蓝图（目标/节拍/必含节拍/禁区）→ 保存
3. **生成**：点单章"生成本章"或"整书生成"，运行面板实时看进度（SSE）
4. **审阅**：阅读器看正文与版本链；diff 页对比相邻版本；不满意可框选段落提交选段重写，或整章回滚/重跑
5. **导出**：详情页导出全书 markdown 至 `data/exports/`
6. **晨检**（挂机后）：`node apps/server/scripts/morning-check.mjs`

### 风格蒸馏（可选）

准备样例文本文件（建议 ≥3 万字），执行：

```bash
pnpm --filter @inkforge/server exec tsx src/style/cli.ts distill --source <样例路径> --name <档案名>
```

蒸馏出的档案绑定到书后，每章生成自动轮换注入 3 段 few-shot 样例；续写模式不注入，用 voice-match 质检把关。
